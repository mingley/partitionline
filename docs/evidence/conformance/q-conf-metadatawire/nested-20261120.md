# Successful Metadata v13 responses

The [three retained body pairs](../../../../tests/fixtures/metadata_wire/v13-nested-pairs.txt)
cover a zero top-level error with populated, mixed and empty results.

| Case | Response fields |
| --- | --- |
| `by-name` | Two brokers with assigned and null racks, UTF-8 and internal topics, distinct topic IDs with partition 0 in each, two leader IDs and epochs, and ordered replica and ISR lists |
| `by-id` | A known topic, a missing ID with null topic name and error 100, and a leader-unavailable partition with empty ISR and an offline replica |
| `known-empty` | An empty topic list with broker and cluster metadata |

On Linux x86_64 with Rust 1.100.0 and Temurin 21.0.13, the exact source
[`55236d1`](https://github.com/mingley/partitionline/commit/55236d1e0fa7d21e5acb94fa3f7bba804e9c219b)
checked all three pairs in both directions for Apache Kafka client SDKs
4.1.0, 4.1.2, 4.2.1 and 4.3.1. Default and all-feature Rust matched the
complete Java-generated bytes. Java parsed the actual Rust re-encodings
and verified every field. The eight lanes checked 24 request/response
pairs in each direction. The retained corpus is 1,338 bytes with
SHA-256 `bdede41302daaffeaf7a3933dea2faed9c20972bfc9c8be185d6661a37b2989a`.
[Exact-source CI](https://github.com/mingley/partitionline/actions/runs/44648227549)

The version probe loaded both generated classes from each SHA-256-pinned
SDK. The 3.9.1 request and response declare v0–v12, so v13 is outside its
range. The other four declare v0–v13. Each run checked its loaded JAR and
recorded the upstream commit and closed process receipts.
[SDK pins](../../../../tests/conformance/java/generate_metadata_wire.py)

Both retained v13 corpus tests passed in both Rust feature profiles in
the checkout and in the extracted crate. Cargo packaged a clean checkout
with `--locked --no-verify` before the extracted tests. Rustfmt and strict
test-target Clippy passed. The earlier five body pairs reproduced their
original bytes. Both existing controls rejected the changed error code.
[Exact checks](https://github.com/mingley/partitionline/actions/runs/44648227549/job/135996207881) ·
[Earlier v13 corpus](README.md)

The first attempt compiled the v13 top-level error setter while probing
3.9.1 and exited before the body tests. The separate version probe fixed
that setup and generated the retained corpus on the second attempt.
[First attempt](https://github.com/mingley/partitionline/actions/runs/44647180075) ·
[Generation](https://github.com/mingley/partitionline/actions/runs/44647746354)
