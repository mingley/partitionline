This source prepares the actual pinned librdkafka2.15 OAUTHBEARER callback
provider with bounded verified libcurl HTTPS client-credentials acquisition.
The historical SDK pin has curl disabled; this is the standard public callback
API, with no native built-in OIDC-provider claim. pins.json records exact SDK
source/library identifiers, HTTP limits, API names and cleanup boundaries.

Metadata uses the real broker router. This native peer does not Produce/Fetch;
the Java and public Rust peers provide the separately selected ordinary RF1
record/history lanes. A callback accepting a local token is not broker proof.
Native -169 authentication errors have unproved origin because a local failed
refresh callback can produce them; protocol58 is recorded separately.

No native compile, SDK socket, or broker live run has been performed for this
source preparation. Exact published-source compiler/runtime receipts and the
full broker qualification barrier must precede execution. The driver and
Linux process owner are in ../driver; all forced/unknown/remaining groups fail
joined-ownership qualification. Private credential and bearer bytes are not
published. Third-party allocations are not claimed completely zeroized.
