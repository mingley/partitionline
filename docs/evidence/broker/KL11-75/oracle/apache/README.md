# Independent ordinary compaction oracle

This lane executes the official Apache Kafka 4.1.2, 4.2.1 and 4.3.1 `Cleaner.doClean`, `UnifiedLog` and `MemoryRecords.filterTo` classes. It imports no partitionline implementation. Exact source/distribution/jar pins and 30 unmodified source references are retained in `pins.json` and `source/`.

The accepted development matrix is `development/matrix-03/validation.json`: six fresh component runs produce 684 actual assertions, 27 positive cases per release and nine malformed-parser observations per release. Nine deliberately wrong expectations detect null-key, horizon-equality and empty-header policy differences. All component bytes and malformed outcomes agree across the three releases and two replays.

Actual Cleaner rounds establish that null keys are discarded inside the mapped cleaning window, including null-key tombstones. A present empty key is retained. The first cleaning of a retained magic2 tombstone sets its delete horizon to cleaning time plus delete retention, independent of record timestamp. Equality expires the tombstone. A previously set horizon remains in a rewritten nonempty batch even after its tombstones disappear; timestamp deltas preserve original record times, maximum timestamp is recomputed, and the original batch offset extent remains.

Cleaner drops an ordinary intermediate batch when all of its records disappear. It retains the final batch of the cleaning round as a 61-byte zero-record header to preserve the last offset, even with producer ID -1. That empty header preserves maximum timestamp and original offsets, clears the horizon flag and sets base timestamp to -1. Caller-selected `filterTo` cases separately exercise `RETAIN_EMPTY` and `DELETE_EMPTY`; those cases do not stand in for real Cleaner policy execution.

Actual protected scenarios preserve both sealed segments beyond the selected window and the active segment byte-for-byte, including after reopen. The null-key inputs enter a delete-policy log before the component switches to compact policy; this does not claim compact-topic Produce admission accepts null keys.

The canonical corpus lives at `partitionline-broker/tests/fixtures/records-compacted/{release}/`. Each authoritative `goldens.json` declares actual batch metadata, record bytes/times/ordered headers, origin, handler policy and round context. Its derived `cases.tsv` columns are name, file, handler policy, batch count, record count, first batch base offset, final batch last offset plus one, and actual record-offset CSV. `-` denotes absent or invalid expectations. The zero-byte output contains no batch; its original logical extent is external storage context.

Nine hostile cases retain actual Apache CRC/parser/iterator outcomes. Apache rejects corrupt CRC, negative/huge count and unterminated varint. Its low-level iterator accepts zero count with extra bytes, negative last delta, records outside the declared extent, wrapped offsets and a trailing byte. The local read contract deliberately rejects those permissive cases; their manifests do not invent an upstream rejection.

Run `prepare-and-run.py --work <fresh-dir> --output <fresh-dir> --fixture-root <fresh-dir>` followed by `derive-tsv.py --fixture-root <generated-fixtures>`. Once the foundation is pushed, `run-final.py --source-sha <exact-sha> --work <fresh-dir> --output <repo-evidence-dir>` archives only this claimed oracle and the compacted fixtures, verifies every Git blob/mode before and after commands, reruns the actual components and reproduces all 114 fixture files.

JVM heap is capped at 128 MiB; map memory is 65,536 bytes, read/write buffers and selected payloads are bounded at 16,384 bytes, inspection at eight batches/128 records, and subprocess deadlines at 60 seconds. These are finite ordinary uncompressed CreateTime component histories. They do not qualify partitionline publication, crash recovery, live peers, performance, replication, transactional/control or producer-state cleaning. Those remain separately owned proofs; parent KL11-11 cannot close from ordinary child KL11-75.
