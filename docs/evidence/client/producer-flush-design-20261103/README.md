# Producer flush design draft

This package contains an unimplemented design, an independent source review, and a small accounting sketch. It does not repair producer flush or establish production readiness or performance. The newer design records proposed responses to the review; those responses have not been independently validated or implemented.

The [design](DESIGN.md) describes admission, per-record ownership, error reporting, cancellation, bounds, transaction boundaries and required checks. The [independent review](REVIEW.md) applies to its separately retained [reviewed snapshot](reviewed-DESIGN.md). The [standalone Rust sketch](epoch-prototype.rs) and [abstract model](check_model.py) do not exercise the actual producer. The sketch was formatted but not compiled or run. The model explored two records and two ordinary flushes; it does not model the fallback, ownership, Tokio or broker behavior.

The [hosted reproduction report](../producer-flush-native-86f2-20261103/README.md) documents run 41674604362: all four selected producer controls failed at their expected assertions under both default and all features. The source under test was commit `45cbff24de76490594970fc962cd04e7be9fafb1` with test-only patch SHA-256 `dcb7fa244056a3ccad7c81ba38611e5cb2157d4a7bdfbe8245cedad2cdfd0c03`. The reproductions used local sockets and injected worker/guard fixtures, not a Kafka broker. Source commit `86f285c706645e68146737a243707953c524b89d` has producer SHA-256 `eb7d6067c3c1e9e1ddfc8c3c140cfc16a889da250429a884c1805f41f13e38d1` and differs from the tested producer only in documentation.

`SHA256SUMS` pins the package files; it is an integrity list, not a signature. No Cargo build, Rust test, broker test or benchmark was run while preparing this design. An actual fix requires choices for cleanup ownership, callback isolation, bounded fallback, transaction fencing and error semantics, then independent concurrency review, native and broker tests, and performance measurement.
