# ApiVersions allocation checks

This records a focused candidate based on commit `923bc2ad8140a726111b52f8971d914e3e9ba355`, tested with uncommitted changes in an isolated worktree. `candidate.patch` is the exact candidate; the recorded sources and `candidate.json` identify its contents. It is not evidence for a later combined checkout without retesting that checkout.

The final runs used Rust 1.99.1 on Linux x86_64 with a fresh dedicated target, cached dependencies, `--locked --offline`, two build jobs and one test thread. The unit run passed 19 tests and the fake-broker run passed two local TCP tests, including a malicious padded array and a valid 100,000-entry response. Strict Clippy passed for the library and fake-broker test. Logs and machine-readable receipts contain the commands, inputs, versions, results, and binary hashes. The final unit binary matches the retained first unit binary by SHA-256. The first Clippy run failed on lint violations in the test helper; the helper was corrected before the final passing tests and lint. A first attempt to launch the final socket run from outside the worktree failed at `git rev-parse`, before Cargo started; the recorded successful run used the correct worktree. External tools and cached dependency contents are not comprehensively byte-hashed; the lockfile is retained.

The default decoded metadata budget is 128 MiB per ApiVersions response. It covers charged vector capacities and feature-name allocations, and is distinct from the input frame limit, allocator overhead and aggregate process memory. A valid, exceptionally feature-dense response may exceed it. The low-level decoder accepts a caller-specified limit; automatic Producer, Consumer and Admin negotiation currently uses the fixed default, with no high-level configuration. Concurrent responses can multiply the per-response budget. This change does not bound all other decoders, prove synchronous parsing meets a scheduling deadline, establish Kafka conformance, or establish production readiness or comparative performance.
