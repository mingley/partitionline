# Produce request planned length

Status: not adopted. This experiment changes the public Produce request encoder;
the ordinary `Producer` uses a separate `encode_produce_body_async` path.
The timings below do not measure client throughput or a Kafka broker.

The request planner already computes each uncompressed batch length before
writing. The first candidate retains the length of the first partition in
the plan and reuses it during writing. Later partitions follow the original
path. This adds no per-partition heap allocation, but also changes the
compressed path's branches and generated code.

On this host the candidate improved several uncompressed shapes, but LZ4 was
slower in all 12 pairs. Its median paired time was 0.99% higher, with pair
ratios from 1.0039 to 1.0243. Snappy's median was 0.75% higher and the
candidate was slower in 9 of 12 pairs. These are small, workload-specific
results on a shared virtual host; they are enough to defer this candidate, not
to establish a universal regression.

The fixture uses deterministic, compressible payloads. It does not measure
zstd, network I/O, a real broker, independent clients, different CPUs,
sustained throughput or production workloads. No global performance ranking
follows from it.

## Checks and limits

Both binaries generated byte-identical 185-case corpora, SHA-256
`68e6849ccc18bf583e1f6b808a4ff29a43de38aa5d997f760b27ca6559c27ecc`.
Cases cover Produce v3–v13, decoded round trips, legacy and flexible fields,
empty and multiple partitions, gzip/snappy/LZ4 and mixed requests, malformed or
oversized inputs, and snapshots after cancellation at three cooperative yield
boundaries. The fixture compares outputs and error strings to the baseline and
uses this crate's own decoder; it is not an independent Kafka implementation.
The malformed/oversized probes are not all expected to fail in every version.

For each source tree, `cargo test --locked --lib produce_request` passed six
focused tests under default features and all features. `rustfmt --check`
and `cargo clippy --locked --all-features --lib -- -D warnings` also passed.
These scoped checks do not qualify the project for production.

The [first attempt](https://github.com/mingley/partitionline/actions/runs/42680556658)
did not reach candidate compilation or measurement: the benchmark fixture
violated the repository's `unused_results` lint. Its
[artifact](https://github.com/mingley/partitionline/actions/runs/42680556658/artifacts/13703131443)
preserves the failure. The successful run corrected the fixture and changed
the single-record payload from null to a 100-byte value.
